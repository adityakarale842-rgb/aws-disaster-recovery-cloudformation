# Disaster Recovery & Business Continuity Solution

## Project Overview

This project focuses on designing a Disaster Recovery and Business Continuity solution using AWS Cloud services.

## Objective

The main objective is to provide backup, failover, high availability, and monitoring for the application.

## AWS Services Used

- Amazon EC2
- Amazon S3
- Amazon VPC
- Amazon EBS
- Application Load Balancer
- Amazon CloudWatch
- AWS IAM
- AWS CloudFormation

## Infrastructure as Code

AWS CloudFormation is used as the Infrastructure as Code (IaC) tool to create and manage the required AWS resources.

## Disaster Recovery Architecture

The solution uses multiple Availability Zones with EC2 instances, Load Balancer, S3 storage, EBS, and CloudWatch monitoring to improve availability and recovery.

## Project Result

The required AWS infrastructure was successfully deployed using CloudFormation and the application was tested successfully.
